## Selected work

### [Morgorithm](https://github.com/steady-kong/2026-Algorithm-Team-Project)

A conversational coffee recommendation app that combines LLM tool use with
from-scratch ranking, sorting, diversification, and blending algorithms. Built
with SvelteKit, TypeScript, and Cloudflare Workers.

### [5G C-V2X for Autonomous Driving](https://github.com/steady-kong/5g-cv2x-autonomous-driving-survey)

An evidence-led survey of whether 5G C-V2X can satisfy the latency and
reliability requirements of autonomous driving, grounded in 3GPP standards and
EU cross-border field trials.
